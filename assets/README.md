# Optional branding

Upload JPEG files with these exact names into this directory:

- `wallpaper.jpg` - desktop wallpaper, ideally 1920x1080 or larger.
- `lockscreen.jpg` - lock-screen image (Windows 11 Pro policy is best-effort; verify manually).
- `profile.jpg` - square account photo.

Missing files are skipped. Upload before choosing the deployment commit: pinned older commits cannot see later uploads. Images are downloaded with the repository before reset and copied into the recovered OS. No network image URL is used by Windows personalization.
